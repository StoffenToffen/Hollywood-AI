# HollywoodAI - Movie Summary AI Application

<img width="2539" height="1439" alt="image" src="https://github.com/user-attachments/assets/9af5dd8f-44d4-49f2-bcc3-2c526c688c0d" />

Developed and deployed a user-friendly platform for AI-powered film summaries, achieving a 93% satisfaction rate based on feedback on accuracy and readability, using Next.js, TypeScript, and Firebase.

## Install Packages
```bash
npm i
```

## Setup .env file

```bash
NEXT_PUBLIC_API_KEY=
NEXT_PUBLIC_AUTH_DOMAIN=
NEXT_PUBLIC_PROJECT_ID=
NEXT_PUBLIC_STORAGE_BUCKET=
NEXT_PUBLIC_MESSAGING_SENDER_ID=
NEXT_PUBLIC_APP_ID=
```

## Start the app

```bash
npm run dev
```
